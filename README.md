# Turza ERP · Demo comercial

Propuesta frontend navegable de un ERP industrial para Embutidos Turza. Usa datos simulados y no necesita backend ni base de datos.

## Desarrollo local

```powershell
npm install
npm run dev
```

## Compilar

```powershell
npm run build
```

El resultado queda en `dist/`.

## Despliegue

- Vercel detecta Vite mediante `vercel.json`.
- Render puede crear el Static Site directamente con `render.yaml`.

Todos los indicadores, clientes, responsables, lotes y operaciones mostrados son ficticios y sirven únicamente para presentar el concepto.
